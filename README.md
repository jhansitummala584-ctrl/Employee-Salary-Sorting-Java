# Employee Salary Sorting - Java

A Java application that stores employee details using ArrayList and sorts employees by salary using the Comparable interface.

## Overview

This project demonstrates how employee objects can be stored in an ArrayList and sorted based on salary using Java's Comparable interface and Collections framework.

## Features

- Store employee details
- Display employee information
- Sort employees by salary
- Display employees before and after sorting

## Java Concepts Used

- Classes and Objects
- Constructors
- Comparable Interface
- Method Overriding
- ArrayList
- Collections.sort()
- `toString()` method
- Method References

## Technologies Used

- Java
- Eclipse IDE

## How to Run

1. Clone or download the repository.
2. Open the project in Eclipse.
3. Run `EmployeeSort.java`.
4. View the employee details before and after sorting in the console.
